# Session Log: T-060 Mask

Date: `2026-05-21`
Thread: `codex-main`

Milestone/Gate: `M2 / Deferred`

## Scope
- Implement explicit `mask` support using the requested `shape` and `contents` child containers.
- Add an `invert` argument so masks can exclude the shape area instead of excluding everything outside it.
- Add a `show` debug argument so authors can inspect only the mask shape layer or only the unmasked content layer.
- Keep future add/intersect/subtract/replace composition modes separate unless they can be given real semantics in this slice.

## Completed
- Added `MaskCommand` to the compiled draw-command model.
- Added schema support for root/group/contents `mask`, `shape`, `contents`, and boolean `invert`.
- Added compiler support for one `shape` container followed by one `contents` container.
- Added implicit mask-shape coverage so shape drawables such as `rect`, `rect-inset`, `circle`, and `polygon` can define mask coverage without visible fill shorthand.
- Added renderer support that rasterizes mask shapes and contents into offscreen layers, then clips content alpha through mask alpha or inverse alpha when `invert=true`.
- Added `show` values `masked-content`, `shape-only`, and `content-only`; omitted `show` defaults to normal masked content.
- Added core compiler/render tests and language-service completion/indentation coverage.
- Replaced the web `mask` placeholder with live examples for normal and inverted masks.
- Simplified mask examples so visible content lives inside `mask` blocks, and changed the window clip example from hatch lines to a gradient fill.
- Updated product spec, roadmap, main-thread state, task board, and decisions.
- Split future add/intersect/subtract/replace mask composition semantics into T-079.

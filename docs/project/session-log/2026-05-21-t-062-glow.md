# 2026-05-21 - T-062 Glow Appearance Support

## Scope
- Add `glow` as a real appearance/effect pass for supported shape drawables and composited groups.
- Support both outer glow and inner glow semantics.
- Reuse the deterministic soft-shadow blur sampler where appropriate without making outer glow pure `shadow` syntax sugar.

## Completed
- Added `GlowAppearance` with `mode`, non-negative `spread`, non-negative `blur`, explicit `alpha`, and either color shorthand or nested `fill`.
- Added `glow` to the shared schema as a `shape-appearance` capability for rectangle-backed shapes, circles, polygons, and composited groups.
- Updated the compiler to collect `glow` alongside existing `fill`, `shadow`, and `stroke` passes.
- Rendered outer glow outside the source contour using the shared box-blur alpha sampling path.
- Rendered inner glow clipped inside the source region by comparing source alpha against a blurred, optionally shrunken core alpha.
- Added group-level glow against the composited child alpha mask.
- Added core tests for schema completions, compiled glow metadata, rectangle outer glow, rectangle inner glow, and group outer glow.
- Added a real web `glow` reference page with live examples and updated group docs for composited glow passes.
- Updated product spec, roadmap, decision log, task board, and main-thread state.

## Behavioral Impact
- Authors can now write:

```text
rect 28 22 124 48
  radius 10
  glow #70c8e8 spread=2 blur=5 alpha=0.7
  fill gradient-linear #18242c #243643
  glow #d8f8ff mode=inner spread=1 blur=4 alpha=0.5
  stroke 1 #d8f8ff
```

- `mode` defaults to `outer`; `mode=inner` clips glow coverage inside the source region.
- `glow #color` is shorthand for a solid glow fill and defaults `blur` to `1`.
- Positive `spread` expands outer glow or pushes inner glow farther inward.
- Group-level glow follows the combined child alpha rather than applying separately to each child.

# Session Log: T-021 Rect Inset

Date: `2026-05-18`
Thread: `t-021-rect-inset`

## Scope
- Add `rect-inset` as the first bounds-relative rectangle convenience command and expose it through the live web examples.

## Work Completed
- Extended the schema registry so the file root recognizes `rect-inset`.
- Implemented `rect-inset` compilation by resolving one inset amount against the current sprite size to produce a normal rectangle draw command.
- Reused the existing rectangle appearance model so `rect-inset` supports:
  - direct color shorthand
  - explicit `fill` children
  - layered solid and gradient fill passes
- Added compiler validation to reject inset values that collapse the rectangle outside the current sprite bounds.
- Added compile and render coverage for `rect-inset`.
- Replaced the `rect-inset` web placeholder page with live editable examples.

## Verification
- Ran `npm run build` at the repo root successfully.
- Ran `npm test` at the repo root successfully.

## Notes
- `rect-inset` currently derives from the full sprite bounds rather than another parent region, which keeps the first version simple and predictable.
- It compiles to the same resolved rectangle draw command shape as `rect` and `rect-absolute`.
